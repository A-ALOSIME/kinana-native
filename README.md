# كنانة نيتف (Kinana Native) - مدير كلمات مرور محلي أصلي 100% بلغة Rust

كِنانة نيتف هي النسخة الأصلية (Native) بالكامل من تطبيق كنانة لإدارة كلمات المرور، تم بناؤها من الصفر بلغة Rust الصافية واستخدام إطار عمل الواجهات الأصلي Slint، للتخلص التام من أي اعتماد على محركات المتصفحات المدمجة (WebView2 / Chromium) أو بيئة Node.js.

## مميزات بنية كنانة نيتف

1. **كود نقي ومستقل 100% بلغة Rust:**
   - تطبيق تنفيذي مستقل ينتج ملفاً واحداً بصيغة `exe` بحجم 15.5 ميجابايت فقط.
   - لا يحتاج لتثبيت محرك WebView2 أو مايكروسوفت إيدج على الجهاز.
   - تشغيل مباشر وفوري بسرعة إقلاع فائقة.

2. **الأداء واستهلاك الذاكرة (Memory Benchmarks):**
   - **عملية واحدة فقط في النظام:** على عكس تطبيقات الويب التي تشغل 6 أو 7 عمليات فرعية لمتصفح إيدج، يعمل كنانة نيتف داخل عملية واحدة فقط (`kinana-native.exe`).
   - **الذاكرة العاملة (Working Set):** تستهلك النواة ورسوميات الواجهة قرابة 150 ميجابايت في وضع الرسوميات النشطة، وتهبط فوراً إلى **2.4 ميجابايت فقط** عند تفريغ صفحات الذاكرة الخاملة في الخلفية أو عند القفل.

3. **أمان التشفير والتعامل مع الذاكرة:**
   - خوارزمية التشفير القياسية المتماثلة: AES-256-GCM.
   - اشتقاق المفاتيح المتين: Argon2id مع أملاح عشوائية (Salts) و Nonces متجددة مع كل عملية حفظ.
   - تصفير الذاكرة الفوري (Zeroize): مسح المفاتيح وكلمات المرور من الرام فور إقفال الخزنة أو انتهاء العمليات.
   - الحافظة الآمنة (Secure Windows Clipboard): حجب كلمات المرور المنسوخة من سجل الحافظة (Win + V) ومن المزامنة السحابية لمايكروسوفت.
   - تكامل Windows Credential Manager: حفظ رمز المرور الرئيسي مشفراً في نظام ويندوز لإتاحة الفتح التلقائي السريع.

4. **واجهة استخدام حديثة ومكتملة:**
   - وضع مظلم أنيق متناسق ومريح للعين مع خط ثمانية العربي المدمج.
   - شاشة إنشاء الخزنة لأول مرة وشاشة الفتح السريع وشاشة استرداد الطوارئ.
   - شاشة رئيسية لعرض الخدمات مع تصنيفات ملونة (تواصل، بنوك، عمل، عام).
   - نافذة تفاصيل الخدمة وإدارة الحسابات الفرعية ومفاتيح الاسترداد والروابط.
   - مولد كلمات مرور مدمج قابل للتخصيص الكامل (الطول، الرموز، الأرقام، الأحرف الكبيرة).
   - نافذة الإعدادات لتغيير رمز المرور الرئيسي وعرض مفتاح الطوارئ وتصدير واستيراد النسخ الاحتياطية المشفرة (.dat).

## هيكل المشروع البرمجي

```
kinana-native/
├── Cargo.toml               # إعدادات المشروع وحزم Rust
├── build.rs                 # معالج تجميع واجهات Slint عند البناء
├── crates/
│   └── kinana-core/         # مكتبة التشفير والنواة والخزنة المستقلة
├── src/
│   ├── lib.rs               # مكتبة المنطق البرمجي (لإتاحة الاختبارات)
│   ├── main.rs              # دورة حياة التطبيق وربط إشارات الواجهة
│   ├── app_state.rs         # إدارة جلسة الخزنة والخدمات والحسابات
│   ├── password_gen.rs      # مولد كلمات المرور عالي العشوائية
│   └── win32.rs             # واجهات Win32 للحافظة وإدارة الاعتمادات والذاكرة
├── tests/
│   └── vault_lifecycle_tests.rs # اختبارات التكامل الشاملة لدورة الخزنة
└── ui/
    ├── appwindow.slint      # الشاشة الرئيسية والنوافذ المنبثقة
    ├── theme.slint          # سمات الوضع المظلم والألوان والخطوط
    ├── fonts/               # خط ثمانية العربي الأصلي (Regular & Bold)
    └── components/          # مكونات الواجهة المخصصة (أزرار، حقول، كروت، حوارات)
```

## طريقة البناء والتشغيل من المصدر

### المتطلبات:
- نظام تشغيل Windows 10 أو 11 (64-bit).
- لغة Rust ومترجم Cargo (إصدار 1.80 أو أحدث).
- أدوات C++ Build Tools الخاصة بـ Visual Studio.

### 1. تشغيل الاختبارات للتأكد من سلامة الكود:
```bash
cargo test
```

### 2. تشغيل التطبيق في وضع التطوير:
```bash
cargo run
```

### 3. بناء النسخة النهائية المحسنة (Release):
```bash
cargo build --release
```
ستجد الملف التنفيذي الناتج داخل المسار:
`target/release/kinana-native.exe`
